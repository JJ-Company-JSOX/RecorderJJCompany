# 录屏编辑第二、三阶段：实现与验证记录

日期：2026-10-23。沿用现有 Electron / React / TypeScript / PixiJS 工程，没有建立第二套 WPF 应用。

这是可构建的开发增量，**不是第二、三阶段已全部验收的 Windows 安装版**。云端 Linux 环境没有真实 Windows 桌面、摄像头、麦克风或 Windows 显卡编码设备。

## 本次实际修改

- 新录制设置面板：独立制作的深色 Jsox 界面和 CSS 插图；按需枚举屏幕或窗口，用户确认后才允许开始。复用已有设备、倒计时、录制、暂停、继续和停止逻辑。导入视频仍打开已有编辑器。不展示未实现的投屏或提词器。
- Windows/Linux 的区域捕获后端目前不支持，面板不提供该模式。没有用截图或全屏录制伪装区域录制。
- 自动缩放按点击间隔及空间距离分组；不同位置的相邻点击保留独立镜头，并在时间中点协调相邻缩放的过渡区间。参数集中在 `AUTO_ZOOM_CLICK_CONFIG`。
- 背景、画布比例、鼠标、摄像头和字幕样式接入现有撤销／重做。仍使用已有预览及导出合成器。
- 修复工程恢复时自定义鼠标运动参数被预设覆盖、字幕字体被默认值覆盖的问题。
- 鼠标点击音效：自制 22 ms PCM 声音，无外部素材和下载；开关、音量进入工程、预设及撤销历史。预览及 MP4 导出共用裁剪、片段排序和变速后的点击时间映射。导出按音源缓存解码结果。
- 导入音频片段新增独立静音、淡入、淡出；控件、工程保存及撤销历史全部接通。预览与离线导出使用同一分段线性包络，处理重叠淡入淡出及导出分块边界。原始音频不改写。录制源音轨的淡入淡出尚未实现，不能据此声称所有轨道都支持。
- 摄像头准备失败时明确提示，屏幕录制继续。
- Whisper 下载前显示约 500 MB 体积、实际目标路径、本地 CPU 性能说明及 MIT 许可。下载由用户触发；新增真正取消网络请求、关闭输出流、清理部分文件、重试及窗口关闭取消。同一时刻仅允许一个模型下载，只有发起窗口可取消；未下载模型权重。
- 完整文件保存前检查目标卷的可用空间；跨卷复制前再次检查。空间不足时返回错误，保留工程、源文件及待保存导出文件。此检查不是渲染开始前的峰值空间预算，磁盘空间也可能被其他进程并发使用。

## 现有能力与边界

仓库已经有本地 Whisper 字幕生成／取消、字幕片段编辑、SRT sidecar、字幕合成、独立摄像头素材、自动缩放／鼠标效果、背景布局、多片段导入及时间投影、源音轨音量和 RNNoise 派生资源、工程原子保存备份、硬件编码试探与软件回退代码。本次复用这些实现；代码存在不等于已在当前机器完成用户的完整验收场景。

新增音频字段为可选字段，旧工程缺省为不静音、无淡入淡出。保留工程版本 2，现有版本 1 圆角转换仍沿用原实现；没有执行用户数据迁移。

## 验证方式

- 全量 Vitest：222 个测试文件通过、5 个跳过；1967 项通过、18 项跳过。包含实际 FFmpeg 混合规格导入／取消及原始素材保留测试。
- TypeScript、生产 renderer / Electron 主进程 / preload 构建，以及主进程 CommonJS 加载检查。
- Playwright 使用真实 Chromium、实际 UI 和 fixture 视频，但 **Electron IPC 使用测试桥接替身**：屏幕／窗口选择、设备设置、中文布局、紧凑窗口、导入、录制启动取消、视觉撤销、音频静音／淡入淡出保存、下载说明及取消入口。
- 实际 OfflineAudioContext 渲染导出音频包络，检查跨分块采样值；浏览器解码实际生成的点击 WAV。无物理音频设备测试。
- 时间轴浏览器场景：首尾裁剪／恢复、重新排序、删除及关联标注音频的撤销。裁剪测试等待真实 resize 光标，避免在布局与命中测试就绪前开始拖拽。
- 旧 `editor-refinements.spec.ts` 中仍有一个针对已移除的 Projects/Presets 弹出框的过时测试；在稳定基线分支上也失败，没有将其作为本次通过项。

## Windows 启动

1. 安装 Node.js 22 或更新版本。
2. 解压源码，双击根目录 `START-DESKTOP.cmd`。脚本在工程目录安装依赖并启动桌面开发版。首次依赖／Electron 下载可能耗时，之后不重复安装。
3. 或在包含 `package.json` 的目录打开 CMD：

```bat
set WHISPER_RUNTIME_ALLOW_MISSING=1
npm.cmd ci --no-audit --no-fund
npm.cmd run dev
```

TypeScript 源码应保存为文件，不要粘贴到 CMD。普通最终用户不需要安装 SDK；上述是开发源码启动方式。本次未产出经过实机验证的 Windows 安装包。

打包沿用 `npm.cmd run build:win:test`（需要对应 Windows 原生辅助程序与 FFmpeg）；完整离线语音包使用仓库原有构建脚本及锁定的语音资源流程，不会由本次增量自动下载模型。
