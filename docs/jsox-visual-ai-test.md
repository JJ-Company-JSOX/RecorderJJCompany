# 本地视觉 AI 剪辑测试版

此版本读取导入视频的 8 张抽样画面，通过本机 Ollama 视觉模型提出缩放和文字标注建议；继续使用现有规则生成剪切/加速建议。所有建议仍需逐项接受或拒绝，应用后可以撤销。没有云端 AI、声音克隆、账号要求或新增遥测。

## 测试前说明：运行时、体积与许可证

- 桌面端没有增加 npm/Python 依赖，不捆绑模型，不在启动时下载或加载模型。
- 可选运行时：[Ollama](https://github.com/ollama/ollama)，MIT 许可证；安装包体积随平台版本变化，本次未安装，体积与硬件性能待测试机核实。官方安装入口：<https://ollama.com/download>。
- 第一候选模型：`qwen3-vl:4b`，官方条目 <https://ollama.com/library/qwen3-vl:4b>。预计为数 GB 的下载；本环境未下载，精确体积/量化版本待核实，不能把参数量当成实际磁盘或显存占用。安装前查看模型页显示的体积和条款。不自动拉取。
- [Qwen3-VL 官方仓库](https://github.com/QwenLM/Qwen3-VL) 的源码许可证为 Apache-2.0；具体权重和 Ollama 量化版本的许可须按相应模型卡核实。MIT/Apache-2.0 源码通常可在保留声明等条件下用于 AGPL-3.0 项目，但这不替代对权重和依赖条款的核对。此测试版通过独立本地服务通信，不再分发 Ollama 或模型权重，Recordly/Jsox 源码继续遵守 AGPL。
- CPU-only 运行速度待实测；预计比合适的 GPU 慢，不能承诺办公电脑交互速度。实际内存和显存取决于量化、模型视觉编码器、上下文以及运行后端。Apple Silicon、Windows GPU 和 Linux CUDA 均未做实机推理测试。单张模型请求 120 秒超时，视频最长 10 分钟，最多 12 张采样；界面默认 8 张。

## Windows 上启动桌面版

从 `jsox-preview` 分支下载完整 ZIP 并全部解压。双击根目录 `START-DESKTOP.cmd`，它检查 Node.js 22+；仅在缺少开发依赖时运行锁文件安装，再启动 Electron 开发版。首次运行会下载 Electron 等已有依赖，不是免安装的正式安装包。它不会安装或下载 AI 模型。

如果已有开发进程，先关闭应用并在原终端按 Ctrl+C。现有电脑可使用 `updates/jsox-visual-ai.zip` 更新源码，保持原依赖；Electron 主进程和 preload 也有改动，必须完整重启，不能只刷新页面。自行改过源码请先备份。

## 准备本地视觉模型

1. 在测试机安装 Ollama。查看上面的运行时和模型说明、官方模型页体积及条款后，再自行执行 `ollama pull qwen3-vl:4b`（也可双击 `PREPARE-VISION-MODEL.cmd`，阅读提示后自行选择是否下载）。该步骤下载模型，会联网；不要在受限网络上偷偷改用不明镜像。
2. 模型下载完后查看 `ollama show qwen3-vl:4b` 及 `ollama show qwen3-vl:4b --license`。记录实际磁盘体积、量化版本、硬件和推理耗时。
3. 退出已运行的 Ollama 托盘服务，再双击 `START-LOCAL-AI.cmd`；它设置本机监听地址和 `OLLAMA_NO_CLOUD=1`，不下载模型。窗口需保持打开。若端口已被占用，先查明现有本地服务，不要把服务绑定到公网。
4. 桌面版中 Import video → Auto edit plan → Generate local plan。展开 Optional local AI review，输入 `qwen3-vl:4b`，点击 Inspect installed model。
5. 界面会显示已安装权重体积、许可证；确认后，另行勾选发送抽样图像给本机服务的说明，点击 Analyze video frames。进度显示已处理样本数。该步骤发送的就是抽样截图，可能包含屏幕上的敏感信息，请先检查自己的视频。
6. 逐项预览并接受/拒绝建议，才可 Apply accepted edits。检查时间线和 Undo。若希望模型审阅规则剪切，再单独点击 Review locally；这只能缩短/移除规则候选，不会发明语义剪切。
7. 关闭面板或点击 Cancel analysis 可取消。失败/取消不会应用部分建议。模型最后一张样本完成时请求卸载；中途取消时缓存最长约 2 分钟，必要时自行 `ollama stop qwen3-vl:4b`。

- 时间线测试覆盖重复素材、变速素材的时间映射、现有编辑保护、未选择时不修改、应用缩放/标注和原规则剪切保留。
- 界面测试用模拟 Electron bridge 与模型结果，验证模型许可确认、图像发送确认、逐项接受、应用和撤销。
- 本环境没有安装 Qwen 权重，没有真实 GPU/CPU 模型推理、Windows 录屏或实际语言准确度结果。

## 真实新马样本验收表

请使用有权处理且已去除敏感信息的真实录屏，不要只用合成语音或字幕拼图。每种语言先至少 5 段，包含不同说话人：中文、英语、马来文、中英马混说。语音含义目前没有转录或输入视觉模型，所以此版不能评估语音理解/转录 WER，须记为“不适用/未实现”，不能记作 0%。

每段预先由人工标记：关键操作和时间、应强调的控件位置、屏幕文字，以及不可删片段。导出 JSON 后逐条检查：

- 重点事件漏检率 = 未覆盖的人工关键事件 / 全部人工关键事件。
- 缩放错误率 = 用户判定位置或时间错误的缩放建议 / 全部缩放建议。
- 抽样画面文字 CER = (替换字符 + 删除字符 + 插入字符) / 人工参考字符数；仅对模型实际输出且有参考的文字计算，同时报告缺失文字，不可用少输出掩盖漏检。
- 剪切误删率 = 人工判定删除重要操作/语音的剪切建议 / 全部剪切建议。逐项报告规则与用户决策，不能归因成模型已理解语音。
- 记录显卡/显存、RAM、模型标签/量化、素材时长、实际抽样数、总耗时、超时/失败数和建议接受率。

结果尚为空，等待测试机与真实样本。默认全视频稀疏采样，快速点击/弹窗会漏掉；640×360 下的小字可能不可读；模型可能复制错字或误定位，不能直接导出为“正确剪辑”。缩放区域结束后由已有动画管线回到普通画幅，动画效果仍须预览验收。
