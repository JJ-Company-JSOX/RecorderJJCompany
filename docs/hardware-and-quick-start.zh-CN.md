# 离线 AI 版：电脑配置与操作方法

适用于当前 Windows 离线语音测试包，不代表其他平台版本或未来 GPU 版的要求。

## 这台电脑的实际情况

2026-10-19 本机读取：Windows 11 Pro x64、Intel Core Ultra 7 155U（12 核 / 14 线程）、系统识别总内存约 15.5 GiB（标称 16GB）、Intel 核显，C 盘约 272.9 GiB 空闲。**这台电脑可以运行当前版本，不需要为了使用这一版 AI 先购买独显。**

真实打包程序的合成英文测试：12.820 秒视频分析约 72.937 秒，剪辑后时间线 10.049 秒，删掉先前重复讲解 2.089 秒。识别、字幕、保存、重开、撤销和有声音的 H.264/AAC 导出通过。这个速度只代表该短样本，不能线性推算长片，也不是中文、真实录音、4K 或录制帧率保证。

## 建议配置

| 项目 | 当前版本的要求或建议 |
| --- | --- |
| 系统 | 优先 Windows 11 64 位（x64）。Windows 10 未进行本版完整验证；本包不支持 32 位 Windows、Windows ARM、Mac 或 Linux。 |
| CPU | x64，需支持 AVX2、FMA、F16C、BMI2、SSE4.2。以 CPU 指令集为准，不能只看 i5/i7 名称。现代多核 Intel Core / AMD Ryzen 是适合评估的范围；老 CPU 兼容性尚未验证。 |
| 内存 | **16GB 是本机跑通的配置，也是建议起点**。8GB 不作为当前完整版的保证配置。4K、较长素材或同时运行多个软件建议 32GB，但尚无相应性能基准。 |
| 显卡 | Intel / AMD 核显可以使用。当前内置 AI 用 CPU；没有启用 CUDA、Vulkan 或 NPU 推理。买 NVIDIA 显卡不会自动加快当前 AI 分析。视频预览和导出另有图形路径，其性能需要分别测量。 |
| 磁盘 | 建议 SSD。至少预留 10GB 用于安装、解包及临时文件，另留录屏、项目和 MP4 导出空间。安装包约 1.88GB，安装后并非同样大小。 |
| 屏幕 | 新面板针对 1024×640 的逻辑视口检查边界和底部按钮；建议 1366×768 或以上。高 DPI 缩放应按实际逻辑视口检查。 |
| 网络 / 其他软件 | 离线 AI 使用内置模型，客户无需联网、账号、API Key、Python、Ollama 或另外下载模型。 |

程序里 3 GiB 的可用内存检查只是 AI 启动门槛，**不是“整机 4GB 就够用”**。Windows、编辑器和视频缓冲仍需要额外内存。AI 模型按需加载，语音和视觉模型先后运行；完成或取消会结束相应模型进程。

Core Ultra 中的 NPU 当前没有使用。插电、选择适合的电源模式、减少其他高负载软件有利于持续运行，但不能替代实测。现阶段优先用这台电脑测试真实素材，暂时不必因这个项目购买新电脑或显卡。

CPU 和软件依据：[Intel 155U 官方规格](https://www.intel.com/content/www/us/en/products/sku/237327/intel-core-ultra-7-processor-155u-12m-cache-up-to-4-80-ghz/specifications.html)、[whisper.cpp 内存说明](https://github.com/ggml-org/whisper.cpp#memory-usage)，以及本仓库的锁定运行程序构建脚本、`electron/ipc/autoEdit/bundled.ts` 和实际验证报告。以上配置建议是工程判断，并非厂商认证或覆盖所有机器的最低配置测试。

## 第一次使用

1. 打开 `Start-Jsox-Offline-Speech.cmd`，或使用完整测试版安装包。无需 Vite，也无需编译。
2. 录制或导入一段带声音的视频。第一次建议用 15–30 秒短片，重复说一句，再说一句不同的操作说明。录屏前确认麦克风或系统声音已开启，录完先回放确认有声音。
3. 编辑器顶部点击 **AI 自动剪辑 / AI auto edit**。右上侧可选择中文界面。
4. 保留「完成后直接应用」和「保持完整画面」两个默认选项，点击 **开始自动剪辑**。界面会显示检查、语音识别、重复讲解分析、画面分析阶段；可以取消，不显示虚构的完成百分比。
5. 出现「剪辑草稿已完成」后点击 **返回编辑器**。播放检查字幕和删减处；不满意用编辑器的撤销恢复，再手动调整。取消“完成后直接应用”则可以先逐条接受或拒绝建议，再点底部应用按钮。
6. 保存 `.recordly` 项目以便下次继续编辑；点击右上角 **Export / 导出**，选择 MP4 和画质并导出。AI 草稿不是最终 MP4，导出仍是独立步骤。

其他分析工具、硬件说明和 JSON 详情默认收起，不需要客户配置。完整 AI 分析当前限制 10 分钟以内，长视频、噪声、口音、复杂叙述可能效果有限。识别不确定或可能涉及独有内容的片段会保留；不能把“没有自动删除”一概当成故障。

这次界面预览另存于 `release/offline-speech-ui-test`，使用该文件夹内的 `Start-Jsox-Offline-Speech-UI.cmd` 和独立的 `%APPDATA%/Jsox-offline-speech-ui-test` 配置，以保留之前打开的版本和用户项目。开发者可用 `npm run build:win:speech-ui` 重建；真实打包测试使用 `node scripts/smoke-offline-speech.mjs --run --executable release/offline-speech-ui-test/win-unpacked/Recordly.exe`。

本版仍是未签名测试版。真实麦克风 / 系统音频、中文语义剪辑、马来语及全新 Windows 安装环境尚未完成全面验证。录屏卡顿和稳定 60FPS 问题也不能用上述自动剪辑成功替代验收。
