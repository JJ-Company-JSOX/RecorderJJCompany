# Jsox Recorder 桌面开发预览

本轮完成主要界面名称、首页与登录入口图标、各现有语言的应用名、原生编辑器标题和托盘名称。首页保留 Recordly / OpenScreen 来源说明。使用自绘 Jsox SVG 标识，无新依赖或模型。

保留 `.recordly` 工程、内部协议、存储标识与现有录屏/编辑管线。安装器 productName、签名、原生平台图标及上游更新渠道尚未完成独立品牌迁移，不能把当前代码打包后当成已经验收的 Jsox 正式安装包发布。其他次要页面仍可能出现上游名称，后续逐项处理。

已有本地自动剪辑开发预览可逐项接受/拒绝建议、下载 JSON，并在应用后撤销；详见 auto-edit-phase-1.md。不含声音克隆，不接入云端 AI。

验证：TypeScript 无输出检查、Vite renderer 生产构建通过；构建报告 CSS 选择器与大文件分块警告，尚未处理。自动剪辑浏览器回归使用模拟 Electron bridge，不等于真实系统捕获验证。

当前运行环境是无桌面显示的 Linux 云端，不能验证 Windows 安装、系统捕获与设备音频。Windows 正式交付前还需要平台构建、签名/安装、权限、录屏、音画同步、导出、工程往返与升级渠道检查。中国大陆网络需在实际当地网络测试。

开发源码包保留仓库构建脚本和锁文件；不包含 node_modules、凭据、构建缓存或 Windows 安装包。开发者可按根目录 README 的平台前提安装依赖并运行 npm run dev。首次安装可能下载 Electron 与原生依赖；这不是面向普通用户的免安装包。

## 无账号本地预览更新

取消未登录强制欢迎页，关闭账号与云端登录客户端，隐藏首页登录/Shared 入口及设置中的账号分类。原账号实现保留在代码中供未来单独开发，当前不启用。其他云端入口只显示可关闭的本地版本说明，不收集邮箱。录屏权限面板与账号独立，未登录也可检查权限和打开录制 HUD。

`updates/jsox-local-mode.zip` 只包含本轮修改的 8 个源码文件，适用于此前 jsox-preview 源码；不是安装器，不更改依赖，不删除工程或视频。更新前关闭开发进程，在项目根目录解压覆盖同名文件后重新运行 `npm.cmd run dev`。如果本地自行修改过这些源码文件，先备份再更新。

录制入口修复：移除 useScreenRecorder.preparePermissions 中残留的账号会话检查。本地录制不依赖账号；macOS 屏幕录制和辅助功能权限检查继续执行。新增 HUD 选择源路径的 Windows/Linux/macOS 模拟平台回归，以及缺少 macOS 系统权限时不得调用选择器的回归。以上不等于 Windows 实机捕获已验证。
