# Windows 内置离线语音剪辑测试版

此版本在现有录屏与编辑器中增加语音识别、保守语义删减、字幕和视觉建议。客户无需安装 Python、Ollama 或服务，无需模型下载、API Key、账号或互联网。联网开发时下载的模型会随安装包提供；应用分析不上传素材。

实际测试结果与保留的失败记录见 [2026-10-19 验证报告](offline-speech-validation-2026-10-19.md)。首次完整正例确实删除了 2.089 秒重复源内容，另保留独有操作说明；12.820 秒样本 CPU 分析约 69.3 秒，不是实时处理或全面质量保证。

## 使用

打开或录制带声音的视频，进入「自动剪辑方案」，点击「一键自动剪辑语音和视频」。默认完成后直接应用可撤销草稿；取消「完成后直接应用」可以先审阅。默认保持完整画面，不新增放大。生成后检查字幕、切点和声音，再使用现有 MP4 导出。

自动应用不叠加屏幕文字标注，以免遮住按钮和任务栏。需要这类标注时，关闭自动应用后先预览、审阅和调整位置；生成的标注框也会保持在画面范围内。

源视频保持原样，时间线通过源时间引用实现删减。当前会保护识别不确定、音频未对齐、已有编辑冲突或可能删去独有内容的片段。去重与重说定位不等于随意压缩全部讲解，更不保证准确理解每段视频。一次撤销可恢复本次应用前的时间线；不代表保存重开之后仍保存完整 Undo 历史。

没有录下的声音无法恢复。无音频视频可使用视觉或本地规则方案。中文/英文/马来语使用同一个多语言模型自动检测，但每种语言的实际质量需要各自验证。

当前完整语音＋视觉分析限 10 分钟以内的视频，按小语句窗口处理，可能遗漏跨窗口很远的重复讲解。CPU 分析不是实时处理；耗时应以实际验证记录为准，不能将快速打开编辑器当作 AI 已完成。

本地测试运行目录为 `release/offline-speech-test/win-unpacked`，请使用 `Start-Jsox-Offline-Speech.cmd`，它使用独立 `%APPDATA%/Jsox-offline-speech-test` 配置。不要使用之前视觉版的启动脚本。无需启动 Vite 或现场编译。测试版暂未签名，不应把本地包当作已完成商业发行审查。

## 构建与自动验证

```powershell
npm run prepare:offline-ai
npm run prepare:offline-speech
npm run build:win:speech
node scripts/smoke-offline-speech.mjs --run
```

前两条仅在开发机获取并校验锁定资产，不在客户启动时执行。`--verify` 或 `npm run verify:offline-speech` 只校验现有资产。`smoke-offline-speech.mjs` 没有 `--run` 或传入 `--help` 时不会启动应用、模型、录制或合成。显式运行只使用独立合成画面、SAPI 写入 WAV 文件和隔离配置，不播放声音、不录制桌面、不上传文件。

自动测试必须证明实际省略了重复讲解的源片段；只加速静音、缩短输出时长不能算语义删除。检查字幕、应用、撤销、保存、重开、H.264/AAC 导出、非静音音轨和音画时长。

## 已定位问题与实现边界

初次真实包测试的 9.885 秒短句样本只有静音加速，**没有删除重复句**：第一遍句子的真实平均词概率约 0.849，第二遍默认词时间戳含静音区和零时长词。原测试仅要求输出变短，不足以验证语义删减；现已加强可复现脚本的验收条件。保留该失败结果，不能将它改称成功去重。

已验证 Whisper 的 DTW 需要同时关闭 flash attention；仅添加 `-dtw small` 会被该版本运行程序忽略。DTW 锚点是时间点，不是精确词边界。它可结合实测静音区给出句段级估计，不应伪造逐字精准定位。无法可靠对齐的内容继续保留，置信度阈值不会为了测试下调。

第二次强验收的 12.820 秒样本已获得正确句段定位，但自由生成剪辑的模型把重复问候语和不同的保存说明错误归组；校验层拒绝，仍未删掉重复句。这次失败也保留。当前流程改为先生成通过词语覆盖、置信度和对齐校验的候选，再让模型按上下文批准候选编号；模型不能重新组合删除范围。缺少实际批准、回复无效、独有内容、否定词或数字差异均不应用。

内置视觉模型按稀疏帧分析；相同任务中完全一致的 JPEG 字节可复用一次推理，仍保留各采样时间，不对相似画面或跨项目复用。单帧观察不能证明真实点击、动作或全部屏幕事件。

支持当前 Windows x64 的 AVX2/FMA/F16C/BMI2/SSE4.2 CPU；无需 NVIDIA。模型只在分析时加载，ASR 与语言/视觉模型先后运行，取消和退出会释放本任务进程。旧 CPU、全新 Windows、真实客户噪声/口音和马来语仍需独立验证。

本阶段未交付多视频自动混剪、全量 OCR/向量检索、精彩片段生成、图库联网检索、配音克隆或云端 AI。其选择依据与阶段验收见 [集成报告](ai-integration-report.md)、[开源矩阵](../OPEN_SOURCE_AUDIT.md) 和 [许可审查](../LICENSE_COMPLIANCE.md)。
