# 本地自动剪辑与批量审阅

本地方案无需登录、云端 AI、付费 API 或下载模型。点击 **Auto edit plan → Generate local plan**，程序使用本机 FFmpeg 检查画面、音轨，以及录制时保存的点击位置。它可以建议点击缩放、同时静音且画面完全不变的停顿删减／加速，以及基于已有转录的文字标注；不会凭空识别没有录下的声音，也不会自动理解整段教程内容。

## 减少逐项操作

1. 生成方案后先预览建议。
2. 可以逐项接受／拒绝，也可以点击 **Accept remaining suggestions（接受剩余建议）** 或 **Reject remaining suggestions（拒绝剩余建议）**。批量操作仅决定尚未选择且不受保护的项目，保留先前的手动选择。
3. 没有待审项目且至少接受一项后，点击 **Apply accepted edits** 才修改时间线。一次 **Undo** 可以撤销这次应用。

可用、受保护、待审和接受数量会显示在方案上方。已有编辑、速度设置和素材变化的保护检查仍然生效；不会为了启用按钮而覆盖原有编辑。可选本地 AI 审阅仍需用户已有模型及明确选择；普通本地方案不需要展开该选项或下载 JSON。

## 全部受保护与音频提示

全部建议受保护时，面板明确提示没有新的修改可应用，可以直接关闭继续编辑。若确实要重新设计已有缩放，先在时间线上审阅现有缩放块，再决定是否手动修改并重新生成方案。始终显示任务栏时，也要考虑自动缩放会改变构图；参见 [整屏录制说明](full-screen-recording.md)。

`Audio is absent or alignment is uncertain` 表示没有足够证据安全生成时间删改。没有音轨与录到了静音是不同情况：前者不会被当成静音来删视频。若回放有声音但仍提示该限制，需要继续核对音轨对齐；不应强制跳过检查。

此次截图对应的本地约 19.17 秒素材，经只读检查只有 H.264 视频轨，没有内嵌音轨；已有 8.293–19.172 秒的缩放覆盖了截图中的点击建议。原文件及项目保留，原始视频和完整诊断没有上传。

需要确认真实录音时，启用需要的麦克风／系统声音，录制一段约十秒的素材，包含说话、点击和任务栏，再回放确认。窗口录制未包含的任务栏及没有录下的声音，不能靠自动剪辑补回。

## 验证（2026-10-18）

26 项方案／应用／视觉建议单元测试通过，覆盖已有编辑保护、时间映射、项目序列化与导出范围、撤销及本地 AI 边界。6 项编辑器 UI 测试通过，覆盖接受／拒绝剩余建议、保留既有决定、跳过受保护项目、全部受保护提示、素材变化后禁止应用、中英马来语切换及撤销；全部受保护场景同时检查 1280×720 窗口，生成按钮不会被长列表挤扁。

首轮新增测试在切换中文后继续用英文对话框名称定位而失败；改为不随语言变化的面板定位后，六项完整重跑通过。类型检查与修改文件的 Biome 检查通过。

生产构建、CJS 启动检查和测试包二进制检查通过。独立测试包位于 `release/autoedit-test/win-unpacked`，使用 `Start-Jsox-Test.cmd` 启动，不需要 Vite 或现场编译。原来运行的程序及用户项目保持打开；使用新版前请先保存并退出旧程序。

另用独立的临时配置启动实际测试包，导入六秒静态画面和静音音轨的合成 MP4，通过真实 FFmpeg／IPC 生成停顿删减建议；批量接受前后均未提前修改时间线，点击应用后保留两端共约 800 毫秒，一次撤销恢复六秒原时间线。五项实际程序检查通过；没有使用用户录屏或替换分析 IPC。合成素材及报告仅存 Git 忽略的 `.tmp`。测试包沿用已有且二进制哈希通过的 native helper，没有重新编译 C++，也没有据此推断 native 捕获性能。

这些变更减少手动决定的次数，不代表录制帧率、预览性能或内存占用已经改善。此次没有重新验证真实麦克风录制、MP4 导出或长录屏分析速度。
